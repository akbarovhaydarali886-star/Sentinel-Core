## 🌟 Flagship Features (5 Dedicated Pages)

### 1. 📊 Executive Portfolio Dashboard
* **Real-time Net Worth & P&L:** Live tracking of multi-currency digital assets + cash balance.
* **6-Month Capital Growth Milestones:** Interactive historical area chart with alpha benchmarks.
* **Asset Allocation Donut Chart:** Live breakdown with clickable trade shortcuts.
* **3D Physical Stitched Wallet Widget:** Interactive physical wallet with sliding Stripe, Wise, and PayPal cards, copyable card numbers, and live balance eye toggle.

### 2. 📈 Pro Spot Trading Terminal
* **Interactive Candlestick / Area / Line Chart:** 1D, 1W, 1M, 1Y multi-timeframe with MA20 indicators.
* **Live Order Book:** Dynamic bids and asks ladder with animated depth bars and spread calculation.
* **Order Execution Terminal:** 25%, 50%, 75%, 100% balance slider, fee calculator, and confetti execution.
* **Recent Market Tape:** Real-time stream of executed buy/sell network trades.

### 3. 🔄 Cross-Chain DEX Swap & Liquidity Hub
* **Instant Token Swap:** Real-time exchange rates across BTC, ETH, SOL, TON, AVAX, NEAR with slippage control.
* **Smart Route Optimizer:** Automated best-route visualizer (e.g. Zenith Vault → Uniswap V3 → Recipient).
* **Liquidity Staking Pools:** ETH/USDC, SOL/USDC, and TON/USDT liquidity staking with real-time APY.
* **Cross-DEX Rate Comparison Table:** Real-time price and fee comparison with Uniswap and Raydium.

### 4. 🧠 Zenith AI Sentinel Co-Pilot
* **Live Interactive AI Advisory Chat:** Real-time market sentiment analysis and portfolio audits.
* **Algorithmic DCA Backtest Visualizer:** 90-day strategy backtest chart demonstrating +34.8% net alpha.
* **1-Click AI Auto-Rebalancer:** Automated portfolio rebalancing engine optimizing for maximum Sharpe ratio.

### 5. 📜 Blockchain Audit & Transactions
* **Complete Audit Trail:** Search and filter transactions by Buy, Sell, Swap, or Deposit.
* **Blockchain Receipt Inspector:** Detailed on-chain receipt modal with Tx Hash, Block Number, and Gas breakdown.
* **Export Reports:** 1-Click CSV and JSON export downloads.

## 🎨 Design & Architecture
* **Tri-Fusion Aesthetic:** Glassmorphism (`backdrop-blur-2xl`) + Neumorphism (tactile beveled depth) + Subtle Neonism.
* **Dual Theme:** Optimized Light Mode & Dark Mode with custom shadow presets.
* **100% Internationalization:** Complete English (EN) and Uzbek (UZ) translations.
* **Interactive Auth Modal:** Uiverse.io Neomorphic design with live 4-criteria password strength meter, email regex check, and social logins.
* **Profile Management Hub:** Avatar picker, 2FA toggle, password updater, and Web3 wallet address copier.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v18 or higher)
* `npm` or `yarn`

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/akbarovhaydarali886-star/Sentinel-Core.git

# 2. Navigate to project directory
cd Sentinel-Core

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Visit `http://localhost:5173` in your browser.
